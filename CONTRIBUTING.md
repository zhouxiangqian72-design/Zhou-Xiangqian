# Contributing to Awesome TRAE

Thank you for your interest in contributing to Awesome TRAE! This document outlines the guidelines for adding resources to this list.

## Getting Started

1. Fork this repository
2. Create a new branch: `git checkout -b add-your-resource`
3. Make your changes
4. Submit a pull request

## Submission Guidelines

### What Can Be Added

- Official TRAE documentation and resources
- Community-built tools, extensions, and plugins
- Tutorials, guides, and learning materials
- Open-source projects built with or for TRAE
- Custom agents, skills, and MCP servers
- Templates and boilerplates
- Blog posts and video tutorials

### Quality Standards

To maintain a high-quality curated list, all submissions should meet these criteria:

- **Relevance**: Must be directly related to TRAE (TraeCode, TraeWork, TraeCode CLI, TraeCode Plugin)
- **Quality**: Well-maintained, documented, and functional
- **Value**: Provides genuine value to the TRAE community
- **Active**: For projects, should have recent activity or be clearly maintained

### Format

Please follow the existing format:

```
- [Resource Name](https://link-to-resource) - Brief description of what it is and why it's useful.
```

For items with a live demo:

```
- [Project Name](https://github.com/user/project) - Description. [Live Demo](https://demo.link/)
```

### Placement

Add your resource to the most appropriate section. If you're unsure, add it to the closest matching section and mention it in your pull request description.

## Pull Request Process

1. Ensure your addition follows the format and quality guidelines above
2. Update the table of contents if you add a new section
3. Submit your pull request with a clear title and description
4. Wait for review — we typically respond within a few days

## Code of Conduct

Be respectful and constructive in all interactions. We're here to build a welcoming community for all TRAE users.

## Questions?

Feel free to open an issue if you have questions about contributing.
